# 2024학년도 공통교양 자료

사용자가 제공한 핵심교양 6영역, 핵심교양 1영역 공학인증, 일반교양 7영역, 창의영역 자료입니다. 원본은 `sources/`에 수정 없이 보관하고 `manifest.json`에 SHA-256과 행 수를 기록합니다. `records.json`은 출처 파일·시트·행, 학수번호, 과목명, 학점, 영역, 주관학과, 인정 종별, 비고를 보존합니다.

- 원본 15개, 과목 행 190개, 고유 학수번호 170개입니다. 창의영역 20개는 일반교양 4영역과 중복되므로 과목을 추가 생성하지 않습니다. 영역별 원본 행은 모두 보존합니다.
- 모든 원본의 인정 종별은 교양선택입니다. 핵심교양 후보 전체를 개별 교양필수로 지정하지 않습니다. 핵심교양 선택·영역 충족 조건은 별도 졸업요건 규칙으로 관리합니다.
- `curriculumYear=2024`는 제공된 자료의 적용 연도입니다. 출력 일시가 2026년이라는 이유로 자료 연도를 바꾸지 않습니다. `금학기 개설`은 원문 비고로만 보존하며 2024년 특정 학기에 실제 개설됐다는 뜻으로 해석하지 않습니다.
- 로컬 `ahni_dev`와 Supabase에는 고유 과목 170개를 공통 교양으로 등록하고, 소프트웨어융합공학과의 2024년 비공개 초안에 161개를 연결합니다. 2025·2026년 연결은 추가하거나 수정하지 않습니다. 실제 수강 자격을 확인한 것으로 간주하지 않습니다.
- 공학인증 과목 `GED1002` 1개, 외국인·교환학생 전용 과목 8개는 원본과 공통 과목 목록에 보존하되 소융 기본 초안에 자동 연결하지 않습니다. 대상 확인 후 연결합니다. 목록은 `manifest.json`의 `deferredLinks`에 있습니다.
- 주관학과는 원본 메타데이터로 보존합니다. 전공 소속으로 오해하지 않도록 공통 교양의 `course.department_id`는 null입니다. 권장 이수 학년·학기는 자료에 없으므로 null입니다.
- GED1~GED6, GEE1~GEE7 영역은 파일 제목과 학수번호 접두사를 대조했습니다. 창의 중복 분류는 원본 레코드와 연결 비고에 보존합니다. 과목명이 같아도 학수번호가 다르면 합치지 않습니다.
- HWP의 지정 6과목 중 `지속가능성을 위한 화학이야기`는 이번 2024 자료에서 확인되지 않았습니다. 학수번호나 연도 연결을 추정하지 않습니다. 나머지 5개 과목은 GED3018, GED4009, GED3015, GED5003, GED3002로 확인됩니다. 별도 선택 그룹 판정 기능의 구현·공개 완료를 의미하지 않습니다.

검증: 백엔드 루트에서 `node --test data/academic/2024/general-education/verify.test.cjs`를 실행합니다. DB 적용은 백업 후 기존 과목 일치, 중복 방지, 비공개 상태, 다른 연도·기존 데이터 보존을 검증한 트랜잭션으로 수행합니다. 이 폴더의 자료를 JPA 시작 시 자동 시드하거나 Flyway 스키마 변경으로 취급하지 않습니다.
