# 공식 학사 자료 보관 및 입력

공식 원본과 조회 자료는 `연도/general-education/` 및 `연도/학과-slug/`으로 구분합니다. 다른 연도의 자료를 복사하거나 누락 과목의 학수번호·학점을 추정하지 않습니다. 같은 학수번호는 기존 `course`를 재사용하며, 과목명이 같아도 학수번호가 다르면 별도 과목입니다.

## 2024~2026 미래융합대학 나머지 4개 학과

[인하대학교 교과과정표](https://sugang.inha.ac.kr/sugang/SU_51001/curriculum.aspx)에서 연도와 미래융합대학 대상 학과를 선택하여 `교육과정` 조회를 12회 실행했습니다. 소융은 완료되어 제외했고 다른 단과대학 자료는 입력하지 않았습니다. 조회·적용일은 2026-10-07입니다.

| 학과 / 보관 폴더 | 2024 연결 | 2025 연결 | 2026 연결 | 보류 연결 |
| --- | ---: | ---: | ---: | ---: |
| 산업경영학과 / industrial-management | 42 | 41 | 41 | 0 |
| 메카트로닉스공학과 / mechatronics | 46 | 45 | 45 | 0 |
| 금융투자학과 / financial-investment | 40 | 39 | 39 | 0 |
| 반도체산업융합학과 / semiconductor-convergence | 13 | 26 | 33 | 0 |

- `source.json`은 공식 XML 필드, 조회 URL, 응답 SHA-256, 조회일·연도·학과를 보존합니다. `records.json`은 종별·권장 학년/학기·영역·원본 비고를 변환한 450행이며 `manifest.json`에 보관 파일 해시, 건수, 보류 목록을 기록합니다.
- 실제 과목으로 명시된 행만 입력합니다. 연도별 행 수는 원본 그대로이며, 특히 반도체 2024의 13행을 다른 연도 과목으로 채우지 않습니다. 이번 표에 없는 공통교양 전체 목록을 네 학과에 자동 연결하지 않습니다.
- 교양필수·전공기초·전공필수·전공선택을 각각 `GENERAL_REQUIRED`·`MAJOR_FOUNDATION`·`MAJOR_REQUIRED`·`MAJOR_ELECTIVE`로 매핑합니다. 명시된 `1,2학기`는 BOTH, 학기 없이 학년만 있는 경우는 null입니다. 영역 코드와 교수명은 추정하지 않습니다.
- 영어 `일반과목군(지정 1과목)`과 핵심교양 택4 비고는 정보로 보관합니다. 후보별 필수 수강 판정이나 졸업요건 테이블을 생성하지 않았습니다.
- 처음 보류했던 `MTH1901 일반수학 1`, `MTH1902 일반수학 2`의 2025·2026 메카트로닉스/반도체 8개 연결은 공통전공 지원 승인 후 보완했습니다. 기존 소융 관리 소속의 MTH1901은 ID·소속을 그대로 재사용하고 MTH1902만 관리 소속 없이 `MAJOR`로 생성했습니다. 인정 분류는 원본의 `MAJOR_FOUNDATION`이며 이름이 비슷한 `MTH1001`과 합치지 않았습니다.

### 적용 및 재사용

로컬 `ahni_dev`와 Supabase에 동일한 442개 연결과 12개 **비공개 초안**을 추가했습니다. 고유 입력 과목 165개 중 기존 9개를 재사용하고 신규 156개를 생성하여 전체 과목은 316→472개, 연결은 730→1,172개입니다. 초안 버전은 1이며 자동 공개하지 않았습니다.

이후 V20 공통전공 지원과 `import-shared-major-courses.sql`로 남은 8개 연결을 두 DB에 추가했습니다. 현재 나머지 4개 학과의 공식 표 450행이 모두 연결되어 전체 과목은 **473개**, 전체 교과과정 연결은 **1,180개**입니다. 대상 4개 초안만 version=2이며 그 외 11개 초안과 소융 730연결은 그대로입니다. 15개 교과과정 모두 비공개입니다. 졸업요건·영어/핵심교양 선택 판정·공개 검토 완료를 의미하지 않습니다.

`import-remaining-department-curricula.sql`은 명시적 데이터 입력 트랜잭션입니다. Flyway 스키마 마이그레이션이나 앱 시작 시 시드가 아닙니다. 동일한 스키마와 대상 4개 학과가 준비된 DB에서 대상을 확인하고 백업한 뒤 `psql -X -v ON_ERROR_STOP=1 -f data/academic/import-remaining-department-curricula.sql`로 실행합니다. 자격 증명은 접속 환경변수로 전달하고 커밋하지 않습니다.

학과/과목 비활성, 기존 이름·학점·분류·소속 충돌, 다른 출처의 초안, 공개된 교과과정, 기존 연결 내용 충돌은 중단합니다. 기존 자료를 삭제하거나 덮어쓰지 않습니다. 같은 자료를 재입력하면 과목·연결·버전·수정시간이 변경되지 않습니다.

`import-remaining-department-curricula.sql`은 **초기 442행 입력 단계**를 보존한 스크립트입니다. 새로운 DB에는 이 스크립트로 초기 초안을 준비하고 V20 적용 후 `psql -X -v ON_ERROR_STOP=1 -f data/academic/import-shared-major-courses.sql`을 실행합니다. 이미 공통전공 8행까지 반영한 DB에는 후속 스크립트만 사용합니다. 초기 스크립트는 추가 연결이 있는 DB를 안전하게 거부하므로 다시 실행하지 않습니다. 후속 스크립트는 해당 4개 초안의 공식 출처·과목 정보·연결 내용과 비공개 상태를 검증하고 없던 연결만 추가합니다. 공개된 초안이나 정보 충돌은 덮어쓰지 않습니다.

공통전공 적용 직전 백업은 Git 제외 폴더 `.env.backups/shared-major-2026-10-07.4t7CWB/`의 local-public.dump와 supabase-public.dump에 권한 600으로 보관했습니다. Supabase는 V19 적용 이력 검증 후 Flyway V20만 적용했고, Flyway 이력이 없는 로컬에는 V20 SQL만 트랜잭션으로 적용했습니다. 기존 CHECK 하나만 제거하며 나머지 제약·RLS·권한은 변경하지 않았습니다.

두 DB에서 공통전공 입력 롤백 검증, 실제 반영, 재입력 무변경 검증을 수행했습니다. 기존 472개 과목·1,172개 연결, 비대상 교과과정과 대상 교과과정의 출처·ID, 학과·학생·전공·성적·관리자·졸업요건·필수과목 데이터 해시는 동일합니다. 과목 정보 충돌·공개된 초안·기존 연결 내용 충돌 부정 시험도 롤백으로 거부를 확인했습니다. 보관 원본 source.json은 수정하지 않았습니다.

적용 전 백업은 Git 제외 폴더 `.env.backups/remaining-curricula-2026-10-07.HqwXWw/`의 local-public.dump와 supabase-public.dump에 파일 권한 600으로 보관했습니다. 개인정보가 포함될 수 있으므로 공유하거나 커밋하지 않습니다.

두 DB에서 롤백 검증, 실제 입력, 재입력 무변경 검증을 진행했습니다. 이름·학점 충돌과 공개된 교과과정 수정은 롤백 전용 부정 테스트에서 거부됐습니다. 기존 과목 316개, 소융 초안 3개 및 연결 730개, 학생·관리자·성적·전공·학과·졸업요건 전체 내용 해시는 보존됐습니다. 스키마·RLS·인증 정책은 변경하지 않았습니다.

검증은 `data/academic/verify-department-curricula.test.cjs`와 `./scripts/verify`에 포함합니다. [작업 계획](../../docs/superpowers/plans/2026-10-07-remaining-department-curricula.md)에는 범위와 보류 사유, 공개 전 후속 작업을 기록했습니다.

## 2025·2026 공통교양

[인하대학교 교양선택영역 교과과정](https://sugang.inha.ac.kr/sugang/SU_51001/curriculum_common.aspx)에서 교육과정 년도를 각각 선택하고, 핵심교양 6영역·공학인증·일반교양 7영역·창의의 조회 버튼을 모두 실행했습니다. 조회일은 2026-10-07입니다.

| 연도 | 조회 영역 | 원본 과목 행 | 고유 학수번호 | 소융 초안에 추가한 연결 | 자동 연결 보류 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 2025 | 15 | 247 | 222 | 213 | 9 |
| 2026 | 15 | 236 | 215 | 207 | 8 |

- `sources/*.json`은 공식 XML에서 학수번호·과목명·학점·영역·주관학과·인정 종별·비고·건수·행 번호를 추출한 자료입니다. 긴 교과목개요 본문은 제외했습니다. 조회 URL, 연도, 원본 응답 SHA-256을 함께 기록합니다.
- `manifest.json`은 각 보관 파일 SHA-256, 실제 행 수, 중복 수, 자동 연결 보류 및 표시 건수 불일치를 기록합니다. `records.json`은 연도·출처 파일·행 번호를 붙인 정규화 자료입니다.
- 공식 뷰어의 `rptrx.js`와 같이 XML 요청 주소의 `%`를 `%25`로 인코딩합니다. 이를 누락하면 `+`가 포함된 조회 값이 변형되어 `DisplayError.htm`을 반환할 수 있습니다. 계정이나 로그인 쿠키는 사용하지 않았습니다.
- 창의영역은 같은 연도의 일반교양 4영역 과목과 중복됩니다. 원본 분류는 모두 보존하고, DB 과목 및 연도별 연결은 하나씩만 생성합니다. 창의 중복 분류는 연결 비고에도 기록합니다.
- 인정 종별은 모두 교양선택입니다. 핵심교양 후보 전체를 개별 교양필수로 지정하지 않습니다. 권장 이수 학년·학기는 자료에 없으므로 null입니다. `금학기 개설`은 조회 시점 비고로 보존하며 해당 연도 특정 학기의 실제 개설 증거로 사용하지 않습니다.
- 공학인증 `GED1002`와 이름에 외국인·교환학생 전용임이 명시된 과목은 공통 과목 목록에 보존하되 소융 기본 초안에 자동 연결하지 않습니다. 대상 과목은 연도별 `deferredLinks`를 참고합니다.

## DB 적용 내역

2026-10-07 로컬 `ahni_dev`와 Supabase에 동일한 자료를 적용했습니다. 두 연도의 고유 학수번호 합집합은 230개이며 기존 과목을 재사용하여 신규 과목 79개만 추가했습니다. 전체 과목 수는 237개에서 316개로 증가했습니다.

- 소융 2024 초안: 211개 연결로 유지합니다. 이번 작업에서 변경하지 않았습니다.
- 소융 2025 초안: 기존 51개에 교양 213개를 추가해 264개입니다.
- 소융 2026 초안: 기존 48개에 교양 207개를 추가해 255개입니다.
- 세 연도 모두 비공개 상태입니다. 학생에게 공개하려면 관리자의 출처·과목 확인과 별도 공개 처리가 필요합니다.
- 기존 과목 237개와 연결 310개의 전체 내용, 학생·관리자·성적·졸업요건 데이터는 적용 전후 해시가 동일합니다. 스키마·RLS·권한은 변경하지 않았습니다.
- 적용 전 public 스키마 백업은 Git 제외 폴더 `.env.backups/general-education-2025-2026-2026-10-07.garIVK/`에 파일 권한 600으로 보관했습니다. 개인정보가 포함될 수 있으므로 공유하거나 커밋하지 않습니다.

`import-general-education-2025-2026.sql`은 검토한 데이터 입력 트랜잭션입니다. Flyway 스키마 마이그레이션이나 앱 시작 시 자동 시드가 아닙니다. 동일한 구조와 기존 소융 2025·2026 비공개 초안이 준비된 DB에서만 사용합니다. DB 대상을 확인하고 먼저 백업한 다음 `psql -X -v ON_ERROR_STOP=1 -f data/academic/import-general-education-2025-2026.sql`로 적용합니다. 접속 정보는 환경변수로 전달하고 명령어나 커밋에 비밀번호를 포함하지 않습니다.

기존 이름·학점·분류·학과 또는 동일 연결 내용이 다르면 덮어쓰지 않고 전체 트랜잭션을 중단합니다. 공개된 자료도 자동 변경하지 않습니다. 동일 초안에 재입력하면 중복 행이나 추가 버전 변경이 발생하지 않습니다.

## 검증 및 후속 확인

`./scripts/verify`에 자료 검증 테스트를 포함했습니다. 원본 보관 파일 해시, 모든 추출 필드, 연도, 학수번호 중복, 보류 목록 및 표시 건수 대조를 검사합니다. DB에는 입력 전 롤백 검증, 입력 후 기존 데이터 보존 및 재입력 검증을 수행했습니다.

HWP의 `지속가능성을 위한 화학이야기`에 대응하는 공식 표기는 2025·2026 자료에서 `GED5004 지속가능성을 위한 화학 이야기`로 확인됩니다. 두 연도에만 연결했으며 2024에 역으로 추가하지 않았습니다. 영어 선택·핵심교양 선택 그룹 판정이나 자료 공개 완료를 의미하지 않습니다.
