# Course Catalog Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Do not dispatch subagents and do not create a worktree.

**Goal:** Add a normalized, authenticated, read-only course catalog that future grade, graduation-requirement, and administrator workflows can share.

**Architecture:** Add `course` as a department-linked JPA aggregate with an immutable external UUID, normalized global course code, exact decimal credit, category, and active state. `CourseService` selects one of four explicit repository queries from optional department/category filters, and `CourseController` exposes only DTOs through `GET /api/v1/courses` with stable errors and OpenAPI documentation.

**Tech Stack:** Java 26, Spring Boot 4.1.1, Spring Data JPA, PostgreSQL 18, Flyway, springdoc OpenAPI 3.1.0, JUnit 5, Mockito, AssertJ, MockMvc, Testcontainers 1.21.4

**Spec:** `docs/superpowers/specs/2026-09-15-course-catalog-design.md`

## Global Constraints

- Work on `feat/course-catalog` in the existing checkout; do not create a worktree.
- Do not use subagents or the removed `ponytail` skill.
- Keep course category separate from future required-course classification.
- Store credit as `BigDecimal`/`numeric(4,1)`, never `float` or `double`.
- Store normalized course codes in uppercase and enforce global uniqueness in PostgreSQL.
- Require a department only for `MAJOR` courses.
- Expose active courses only and require a valid JWT for the API.
- Every HTTP change includes controller tests, OpenAPI success/error examples, security requirements, and the checked-in contract.
- Follow Controller -> Service -> Repository -> Entity and never expose JPA entities.
- Use TDD and commit each independently testable task.
- Use only `feat`, `fix`, `docs`, `refactor`, or `chore` commit prefixes.
- Run `./scripts/verify` before the final push.

```sql
CREATE TABLE public.course (
    id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    entity_id uuid NOT NULL DEFAULT gen_random_uuid(),
    department_id bigint,
    code varchar(30) NOT NULL,
    name varchar(200) COLLATE ahni_korean NOT NULL,
    credit numeric(4,1) NOT NULL,
    category varchar(30) NOT NULL,
    is_active boolean NOT NULL DEFAULT true,
    created_at timestamptz NOT NULL DEFAULT now(),
    updated_at timestamptz NOT NULL DEFAULT now(),
    CONSTRAINT uk_course_entity_id UNIQUE (entity_id),
    CONSTRAINT uk_course_code UNIQUE (code),
    CONSTRAINT fk_course_department FOREIGN KEY (department_id) REFERENCES public.department (id),
    CONSTRAINT ck_course_code_uppercase CHECK (code = upper(code)),
    CONSTRAINT ck_course_credit CHECK (credit >= 0.0 AND credit <= 30.0),
    CONSTRAINT ck_course_category CHECK (category IN ('MAJOR', 'GENERAL_EDUCATION', 'ELECTIVE')),
    CONSTRAINT ck_course_major_department CHECK (category <> 'MAJOR' OR department_id IS NOT NULL)
);

CREATE INDEX idx_course_department ON public.course (department_id);
CREATE INDEX idx_course_active_category ON public.course (is_active, category);
```
