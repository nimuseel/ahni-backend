# 미래융합대학 나머지 학과 2024~2026 교과과정 입력

## 범위와 확인 결과

공식 출처: https://sugang.inha.ac.kr/sugang/SU_51001/curriculum.aspx
조회일: 2026-10-07. 교육과정 년도를 선택하고 미래융합대학 학과별 `교육과정` 조회를 실행한다.
대상은 현재 서비스에 등록된 산업경영·메카트로닉스·금융투자·반도체산업융합 4개 학과이다.
소프트웨어융합공학과는 완료되어 제외하며 다른 단과대학은 추가하지 않는다.

| 학과 | 2024 원본 행 | 2025 원본 행 | 2026 원본 행 |
| --- | ---: | ---: | ---: |
| 산업경영학과 | 42 | 41 | 41 |
| 메카트로닉스공학과 | 46 | 45 | 45 |
| 금융투자학과 | 40 | 39 | 39 |
| 반도체산업융합학과 | 13 | 26 | 33 |

## 입력 계약

- 원본 450행, 학수번호 167개를 연도·학과별 보관한다. 학수번호가 같은 과목은 재사용한다.
- 이름·학점·과목 분류·전공 소속 충돌, 비활성 학과/과목, 공개된 교과과정은 덮어쓰지 않고 트랜잭션을 중단한다.
- `교양필수→GENERAL_REQUIRED`, `전공기초→MAJOR_FOUNDATION`, `전공필수→MAJOR_REQUIRED`, `전공선택→MAJOR_ELECTIVE`로 변환한다.
- 권장 학년과 명시된 학기만 변환한다. 학기 없는 `1학년` 등은 학기를 null로 남긴다. `1,2학기`만 BOTH로 변환한다.
- 원본 영역명은 areaName, 전공영역은 majorArea, 선택 과목군·비고·교양 구분은 note에 보존한다. 존재하지 않는 영역 코드는 만들지 않는다.
- 다른 연도 과목을 대체 입력하지 않는다. 교수·실제 강의 개설·졸업요건 판정은 이번 입력에 포함하지 않는다.
- 영어 지정 1과목과 핵심교양 택4 규칙은 출처 정보로 보존할 뿐, 모든 후보가 각각 필수라는 졸업 판정을 생성하지 않는다.
- 기존 공통교양 목록을 이 네 학과에 자동 복제하지 않는다. 이번 요청의 학과별 공식 표에 명시된 행만 연결한다.
- MTH1901 일반수학 1, MTH1902 일반수학 2는 2025·2026 메카트로닉스/반도체에 공통 전공기초로 지정되어 있다. 현재 Course/CurriculumService의 단일 전공 소속 검증과 충돌하므로 8행을 보류한다. 임의로 한 학과를 소유자로 정하거나 교양으로 바꾸지 않는다. 별도 설계 승인 후 처리한다.
- 따라서 입력 대상은 442연결·고유 165과목이다. 보류한 MTH1901은 기존 소융 소속이며 변경하지 않고, MTH1902는 신규 과목 생성도 보류한다. 기존 교양 9과목을 재사용하고 신규 156과목을 추가한다. 12개 교과과정은 전부 비공개 초안이다.

## 실행 결과

2026-10-07 두 DB에 442연결·12비공개 초안을 입력했다. 기존 316개 과목을 보존하면서 신규 156개를 추가해 전체 472개이다.
소융 교과과정 3개/730연결 및 사용자 데이터 해시가 입력 전후 동일하다. 재입력 이후 전체 데이터/버전/수정시간 해시도 동일하다.
과목 학점 충돌과 공개 자료 수정은 롤백 전용 부정 검증에서 두 DB 모두 거부됐다.
자료 검증 12개 및 기존 공통교양 검증 3개, 자동 PR 테스트 10개, Java 단위·통합 테스트가 통과했다.
원본의 공통 전공기초 8연결은 범위 확대 없이 보류했다. 신규 코드·스키마·RLS 변경은 없다.

## 검토 초점

학과명이 비슷한 다른 단과대학 자료, 학수번호와 과목명 혼동, 학기 미명시를 BOTH로 추정하는 오류,
학과 간 공통 전공 과목의 임의 소속 변경, 영어 선택 그룹의 필수 수강 오판을 확인한다.
원본 학과/연도별 목록과 DB 목록을 필드 단위로 대조하며, 전체 서비스 테스트도 실행한다.

## 남는 작업

위 실행 결과는 초기 442행 입력 시점의 기록이다. 이후 사용자 승인에 따라 `feat/shared-course-recognition`에서 기존 `curriculum_course`를 활용해 공통전공을 인정하고 V20으로 관리 소속 필수 CHECK만 제거했다. 과목 마스터를 복제하지 않으며 졸업 전공학점은 공개된 학과·수강연도·과목 연결 기준이다. 총학점·GPA·재수강 대체와 입학년도별 졸업 정책은 유지한다.

보류했던 MTH1901/MTH1902 8개 연결을 로컬·Supabase에 반영하여 공식 표 450행을 모두 입력했다. 현재 전체 과목 473개·교과과정 연결 1,180개이며 모든 초안은 비공개이다. 적용·보존·재입력 검증과 백업 위치는 `data/academic/README.md`에 기록한다.

각 학과의 공통교양 연결 범위 확인, 관리자 검토 후 공개 및 별도의 졸업요건 입력은 이번 데이터 등록 완료와 구분한다. 복수전공 중복 인정 정책이나 학교의 최종 졸업 인증은 확정하지 않았다.
